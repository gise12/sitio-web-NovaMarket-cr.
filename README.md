📌 Descripción del proyecto

NovaMarket CR es una tienda virtual costarricense especializada en la venta de artículos para el hogar, incluyendo productos de limpieza, decoración, organización y accesorios para interiores y exteriores.

Este proyecto busca ofrecer una experiencia de compra sencilla, organizada y accesible. Además, incluye una propuesta de sistema de inventario y ventas para facilitar el control de los productos y mejorar la administración de la tienda.

🎯 Objetivo general

Desarrollar una plataforma digital para presentar los productos de NovaMarket CR y proponer un sistema de inventario y ventas que permita administrar los productos, registrar las ventas y mantener actualizadas las existencias.

🛍️ Productos

Entre los productos que ofrece NovaMarket CR se encuentran:

- Escobas y trapeadores.
- Detergentes y artículos de limpieza.
- Mesas y estanterías.
- Cortinas de baño.
- Lámparas y alfombras decorativas.
- Organizadores y recipientes.

💻 Funcionalidades del proyecto

Tienda virtual
- Página de inicio.
- Información sobre la empresa.
- Catálogo de productos.
- Página de contacto.
- Acceso al sistema de inventario y ventas.

Sistema de inventario y ventas
- Inicio de sesión para el personal autorizado.
- Registro de productos.
- Consulta de productos y existencias.
- Modificación y desactivación de productos.
- Registro de ventas.
- Actualización del inventario después de cada venta.
- Reportes y resúmenes de ventas e inventario.

*Nota: las funciones del sistema que todavía no estén programadas forman parte de los objetivos de desarrollo del proyecto.*

👥 Usuarios del sistema

- **Administrador:** gestiona los productos y supervisa el sistema.
- **Personal de ventas:** registra las ventas y consulta los productos.
- **Personal de inventario:** revisa y actualiza las existencias.
- **Gerencia:** consulta los reportes y resultados de la tienda.

🛠️ Tecnologías utilizadas

- HTML5: estructura de las páginas.
- CSS3: diseño y estilos visuales.
- JavaScript: interactividad y validaciones.
- Canva: elaboración de prototipos de interfaces.
- Trello: organización de tareas mediante Scrum.

📁 Estructura del proyecto

- `index.html`: página principal.
- `nosotros.html`: información de la empresa.
- `productos.html`: catálogo de productos.
- `contacto.html`: formulario de contacto.
- `sistema.html`: acceso o presentación del sistema.
- `login.html`: pantalla de inicio de sesión, si se incluye en la versión actual.
- `css/estilos.css`: estilos de las páginas.
- `js/`: archivos JavaScript.
- `img/`: imágenes y recursos gráficos.
- `imagenes/`: prototipos y diseños de las interfaces, si se conservan en esta carpeta.

🔄 Organización del proyecto

El equipo de trabajo está compuesto por cuatro integrantes. Para organizar el desarrollo se utiliza Scrum, con los roles de Product Owner, Scrum Master y equipo de desarrollo.

El proyecto se divide en dos Sprints:

- *Sprint 1:* funcionalidades prioritarias, como el registro y consulta de productos, las ventas y la actualización del inventario.
- *Sprint 2:* funcionalidades adicionales, como la modificación y desactivación de productos, los reportes y las pruebas del sistema.

Las tareas se organizan en un tablero con los estados Pendiente, En proceso, Revisión y Finalizado.

▶️ Cómo abrir el proyecto

1. Descargar o clonar el repositorio.
2. Abrir la carpeta del proyecto.
3. Ejecutar el archivo `index.html` en un navegador web.
4. Navegar por las páginas utilizando el menú principal.

🔐 Seguridad

El sistema debe proteger el acceso a la información y restringir las funciones según el tipo de usuario. Si se utiliza únicamente HTML, CSS y JavaScript sin un servidor, el inicio de sesión es una demostración y no proporciona seguridad real para datos sensibles.
